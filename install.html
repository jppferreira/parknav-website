Install

Get ParkNav on this Wi-Fi.

Android can install the APK from this page. iPhone cannot sideload an unsigned app over Wi-Fi — the route for that is below.

Android

Download the APK

Same Wi-Fi as this computer. Open this page on your phone, tap download, then allow install from the browser.

Download ParkNav.apk

01

Tap download

Chrome or Samsung Internet will save the file. If Android warns that the file is from an unknown source, that’s expected for a direct APK.

02

Allow this browser to install

Settings → allow from this source, then Open. ParkNav is signed for testing, not Play Store.

03

Open ParkNav

The app is standalone — you don’t need Expo Go on Android.

Scan

Phone on the same network

Wi-Fi install isn’t available the same way

Apple only lets you install apps that are signed with an Apple Developer certificate (TestFlight, App Store, or a USB install from Xcode). An IPA dropped on this Wi-Fi page would not open on a normal iPhone.

What we can do on iOS

Install Xcode from the Mac App Store, plug the iPhone in, trust the computer, then run a device build. That installs a real ParkNav app for about 7 days with a free Apple ID, or longer with a paid Developer account.

Test over Wi-Fi today

Install Expo Go from the App Store, then scan the QR code from npx expo start on this Mac. That’s the JS app, not a standalone ParkNav icon.

Later: TestFlight

With the Apple Developer Program (£99/year), EAS can build an IPA and you install through TestFlight over Wi-Fi — that’s the proper iOS equivalent of this APK link.
